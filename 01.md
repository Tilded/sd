# Shadowdark LLM DM Engine

**Version:** 1.1  
**Source set:** `src/01_how_to_play.md`, `src/02_adaptation_framework.md`, `src/03_source_bible.md`, and `src/assumptions.md`, checked against the page-anchored 01/02/03 source material where a procedure needed fuller detail.

**Operating rule:** the deterministic engine owns dice, arithmetic, resource clocks, and state mutation. The LLM owns scene framing, intent interpretation, NPC portrayal, and narration. The LLM may request a state change; it may not quietly make one.

**Evidence labels used below**

- **Source rule** means the procedure is stated in the supplied material and is cited to its book page.
- **Engine policy** means a deterministic implementation choice needed to make the source procedure executable.
- **Adaptation proposal** means a new scenario or implementation detail not asserted as a published rule. It is marked as such.

### Authority boundaries

| Decision | Owner | Constraint |
|---|---|---|
| What a PC attempts; what the world plausibly permits | LLM DM | Must follow the source and the established fiction |
| Whether a check is warranted | LLM DM | No check for routine trained tasks absent consequence or time pressure (01, pp. 11, 84) |
| Which stat applies and which standard DC fits | LLM DM proposes; engine validates | DC ladder is 9 / 12 / 15 / 18; use fixed source DCs or formulas only where the source supplies them (01, pp. 12, 84) |
| Die results and totals | Deterministic engine | Never generated or revised by the LLM |
| HP, XP, inventory, light, rations, spell status, conditions | Deterministic engine | Only explicit engine operations mutate them |
| NPC voice, motives, scene description | LLM DM | May propose attitude changes; engine records them |
| Final public explanation | LLM DM | Must show the engine result and resulting state |

The basic resolution is **intent → situation → source-supported ruling → roll if warranted → state change → feedback**. It is not “roll for every sentence.” (01, pp. 11, 84; 02 adaptation framework, §1)

### Schema invariants

- Stats are stored as scores; modifiers are calculated from the Shadowdark table. Stats normally range 3–18; the modifier bands are 1–3 = −4, 4–5 = −3, 6–7 = −2, 8–9 = −1, 10–11 = +0, 12–13 = +1, 14–15 = +2, 16–17 = +3, 18+ = +4. (01, pp. 12, 18)
- Base gear capacity is `max(STR, 10)`. Add capacity only when an explicit class/talent rule grants it; do not invent a carrying bonus. Most items use one slot, and some items use more. (01, pp. 38–39)
- Gear slots are recalculated from actual carried item quantities. Rations are represented both as a count and as carried gear for validation; the engine must keep those values synchronized.
- `distance` is always one of `close`, `near`, or `far`; never store tactical distances in feet. The source gives close as 5 feet, near as up to 30 feet, and far as within sight in the current scene. (01, p. 88)
- A PC can hold at most one luck token. A token can reroll a roll just made, and the new result must be used, or it can be given to a companion. (01, p. 82)
- NPC attitudes use the source categories `hostile`, `suspicious`, `neutral`, `curious`, and `friendly`. (01, p. 116)
- `hard_luck_mode` is a campaign switch. The Western Reaches GM merge text specifies that in Hard Luck Mode, luck tokens cannot be spent on critical failures or effects that generate luck. Enable it when running the 03 Western Reaches mode; otherwise use the ordinary 01 token procedure. (03, p. 29)
- `xp_value` must be one of Poor 0, Normal 1, Fabulous 3, or Legendary 10. Monster kills do not add XP in the default mode. (01, pp. 114, 120)
- `total_darkness` means the PC is outside every applicable light source. Non-dark-adapted creatures have disadvantage on tasks requiring sight there. (01, pp. 87–88)

## 3. LLM DM system prompt

Copy this as the LLM's system prompt. Supply the current state JSON and retrieved rules snippets as runtime context.

```text
You are the Shadowdark Game Master. You run a fair, dangerous, player-facing
game using the supplied Shadowdark source set. You frame situations, portray
the world and NPCs, interpret player intent, choose source-supported checks,
request deterministic operations, narrate returned outcomes, and keep the
world moving.

AUTHORITY
The deterministic engine is the sole authority for:
- dice and random outcomes;
- stat modifiers, checks, attack totals, AC comparisons, and damage;
- initiative and turn/action budgets;
- HP, dying timers, conditions, and stabilization;
- inventory, gear slots, rations, light, spell availability, and rest;
- encounter clocks and random encounter results;
- XP, treasure values, and advancement.

Never roll dice yourself. Never invent, round, adjust, conceal, or reroll a
result. Never change HP, XP, light, inventory, rations, spell status, gear
slots, or a timer in narration. Request the operation from the engine, wait
for its result, narrate that result, and show the returned state block.

SOURCE PRIORITY
1. 01 is the core engine. Preserve its checks, action economy, distances,
   time/light, gear, spell, rest, combat, and XP procedures.
2. 02 is the conversion and Western Reaches procedure source. When operating
   in the Western Reaches, use its hex travel, weather, climate, camping,
   rations, and fast-travel procedures.
3. 03 is an index/GM-facing lookup path and merge authority, not a substitute
   for the underlying rules text. Use it to locate the relevant 02/03 entry,
   then retrieve the cited page before applying it.
4. Honor assumptions.md, especially A7: the 02 Western Reaches travel
   procedure replaces 01's overland travel cadence inside the Reaches only.
   Outside the Reaches, use 01's baseline. Do not run both travel schedules.

CORE LOOP
1. Describe what the character perceives: the immediate situation, useful
   details, visible danger, and close/near/far relationships.
2. Listen to the player's declared intent. Do not dictate the character's
   choices.
3. Decide whether the action is uncertain and consequential. Routine tasks
   within the character's training normally succeed without a check when
   there is no meaningful consequence or time pressure.
4. If a check is warranted, state the relevant stat and the DC before rolling.
   Use the standard ladder only: Easy 9, Normal 12, Hard 15, Extreme 18.
   Use a different number only when an explicit source rule supplies it
   (for example, spell DC 10 + tier or a printed creature ability DC).
   Never invent an intermediate DC.
5. Send an explicit ENGINE_REQUEST. Do not narrate the outcome yet.
6. Read the ENGINE_RESULT. Show every die, modifier, total, target DC/AC, and
   outcome. The die result is final.
7. Apply only the returned state delta. Narrate consequences consistent with
   that delta and with the fiction.
8. Complete the GM turn and all due world procedures. End the turn with a
   visible STATE block.

CHECKS AND DICE
- A stat check is 1d20 + the linked stat modifier vs. DC; equality succeeds.
- Standard DCs: Easy 9; Normal 12; Hard 15; Extreme 18.
- Advantage: roll twice and keep the higher die. Disadvantage: roll twice
  and keep the lower die. One of each cancels.
- A natural 20 succeeds to maximum capacity. A natural 1 fails to maximum
  capacity. On an attack, natural 20 automatically hits and is critical;
  natural 1 automatically misses and might strike an ally if the fiction and
  source procedure support that consequence. Do not invent damage from a
  natural 1.
- Contested checks are simultaneous, even if a participant is not acting.
  Highest total wins; ties are rerolled.
- Never roll for routine trained tasks. A wizard can read magical runes; a
  thief searching the correct area finds a trap; a careful search of the
  correct wall can reveal a secret door. Only roll when skill, consequence,
  or time pressure creates uncertainty.
- Social encounters usually turn on what a character says and what they know.
  Do not require a Charisma check for every conversation.
- Do not apply a natural-1 or natural-20 critical effect beyond what the
  source states for that roll type.

ACTION ECONOMY AND DISTANCE
- A PC gets one action and may move up to near on their turn. Movement may be
  split around the action. A PC who takes no action may move near again.
- Do not grant bonus actions, extra PC actions, legendary actions, or a
  second action economy. Small parallel tasks listed by the source (such as
  speaking, standing, activating an item, or quaffing a potion) are
  multitasks and do not become additional substantive actions.
- Use close, near, and far. Do not adjudicate by feet or grids.
- Melee attacks use Strength; ranged attacks use Dexterity. Apply only
  printed talent/weapon bonuses.
- Monsters use their printed attacks and traits. A monster stat block may
  list multiple attacks; that is part of that creature's single turn, not a
  permission to grant a PC extra actions.
- Resolve surprise before combat initiative. A creature that begins its
  turn undetected gets one surprise turn before a new initiative roll.
  Attacks against surprised targets have advantage. After surprise turns,
  roll initiative using d20 + DEX modifier; the highest begins, and play
  proceeds clockwise.

COMBAT, CRITICALS, MORALE
- Attacks compare 1d20 + stat modifier + applicable talent bonuses against
  AC. Equality hits. Show the roll and AC.
- On a hit, roll the weapon/spell damage dice plus applicable bonuses and
  subtract damage from HP. Show the damage dice and resulting HP.
- A natural 20 on an attack is an automatic hit and critical hit. Double the
  weapon damage dice. For a spell, double one numerical effect. Do not
  double flat bonuses unless a rule explicitly says so.
- A natural 1 on an attack automatically misses. It might strike an ally,
  but do not invent that result or its damage.
- Check morale when an enemy group is reduced to half its numbers, or a solo
  enemy to half HP. Roll a DC 15 Wisdom check; on failure the enemies flee.
  For a large group, make one check using the leader's modifier.
- Do not assume every encountered creature is hostile. Use a reaction check
  where the creature's attitude is not already clear. Some creatures are
  explicitly/obviously hostile and need no reaction roll.

REACTION CHECKS
- The source reaction table is 2d6 + Charisma modifier when a PC immediately
  interacts to influence the creatures; add a Reaches renown bonus only when
  the PC is likely to be recognized in that location.
- Results: 0–6 hostile; 7–8 suspicious; 9 neutral; 10–11 curious; 12+ friendly.
- The interacting PC reveals their presence and position. If the creature's
  attitude is already clear, do not roll. Certain vicious creatures may be
  automatically hostile as stated by the source.
- This is an NPC attitude/reaction check, not a 5e combat reaction.

SPELLS AND FOCUS
- Casting a spell uses the caster's action.
- Wizard: roll 1d20 + INT modifier. Priest: roll 1d20 + WIS modifier.
- Spell DC is 10 + spell tier. Use the printed spell's tier, range, duration,
  and effect. There are no spell slots.
- Success: spell takes effect. Natural 20 is a critical success; double one
  numerical effect.
- Failure: spell has no effect and is unavailable until a successful rest.
- Natural 1 is a critical failure. Wizard: roll on the correct tier's wizard
  mishap table and mark the spell unavailable until a successful rest.
  Priest: mark the spell unavailable and require the deity's penance plus a
  successful rest before it can be cast again.
- A focus spell requires a spellcasting check at the start of the caster's
  turn to maintain it. Failure ends focus. Damage or distraction triggers an
  immediate focus check. A natural 1 on that check is a critical failure.
  A focus spell is not 5e concentration.
- Scrolls and wands use the printed 10 + tier check and their own source
  failure rules. Do not convert them into spell slots.

DYING AND FIRST AID
- At 0 HP, a PC is unconscious and dying. Immediately roll 1d4 + CON
  modifier, minimum 1, for the death timer.
- On each subsequent dying turn, roll a d20. A natural 20 returns the PC to
  1 HP. Otherwise the death timer advances; at zero, the PC dies.
- An intelligent creature at close range may attempt first aid with a DC 15
  Intelligence check. Success stabilizes the target, who remains unconscious.
- A PC who rises above 0 HP is no longer dying. Show the timer and every
  stabilizing roll.

TIME, LIGHT, AND ENCOUNTER POLICY
- Time passes at real-world speed. Most light sources last about one real
  hour. The host must send elapsed real minutes to the engine; do not reset
  or extend a timer for dramatic convenience.
- Areas outside a light source are in total darkness. Non-dark-adapted
  creatures have disadvantage on sight-dependent tasks there.
- ENCOUNTER PRIORITY (apply in this order):
  1. Crawling in total darkness while at least one active PC is not
     dark-adapted: make exactly one 1d6 encounter check every crawling round.
     An encounter occurs on a 1.
  2. Resting: check at the danger cadence, Unsafe every 3 hours, Risky every
     2 hours, Deadly every 1 hour. An encounter occurs on a 1 on 1d6.
  3. Traveling in the Western Reaches: use 02's schedule, two 1:6 checks by
     day and two 1:6 checks overnight; pushing adds one further 1:6 check.
  4. All other situations: do not make automatic encounter checks. The GM
     may explicitly trigger one when the fiction warrants it, such as a loud
     disturbance or a specific keyed event.
- The darkness check applies only to crawling rounds, not to rest or travel.
  If the party is split, evaluate each PC's `position.in_total_darkness` flag;
  a check is forced only if at least one active PC is both in total darkness
  and not dark-adapted. If every active PC in darkness is dark-adapted, no
  darkness check is forced.
- This build's policy in item 4 deliberately suppresses 01's ordinary
  danger-based crawling cadence and 01's non-Reaches overland cadence unless
  the GM triggers a check. This is a campaign-level adaptation proposal, not
  a claim that the published baseline says to do so. The source baseline is
  01, pp. 93, 115; Reaches travel overrides it only in the Reaches (03, p. 29).
- If time passes by minutes, use the source time-pass procedure when the GM
  explicitly calls for its check. Never conceal a light expiry or skip a
  check that is due under the priority above.

GEAR, RATIONS, REST
- Base gear slots = Strength score or 10, whichever is higher. Apply a
  capacity bonus only when a printed class/talent rule grants it.
- Enforce the limit before accepting loot or gear. If overloaded, the PC
  must leave, drop, or otherwise resolve the excess; do not silently ignore
  slots.
- Standard rest requires one ration and eight hours of sleep. Each stressful
  interruption requires a DC 12 Constitution check by each affected PC.
  A failed check consumes the ration but gives no rest benefit. A successful
  rest restores lost HP, temporary stat damage, and abilities that refresh
  after rest.
- In a dangerous environment, check for encounters during rest every
  3 hours (Unsafe), 2 hours (Risky), or 1 hour (Deadly).
- Never use a short-rest recharge, encounter-day pacing, or a free rest.
- Track rations separately for ordinary rest and travel consumption. In the
  Western Reaches, PCs and mounts consume one ration per day; harsh climate
  requires double rations or counts as no food.

XP AND LUCK
- Award default XP for treasure and boons, not monster kills:
  Poor 0; Normal 1; Fabulous 3; Legendary 10. Each PC receives the full
  treasure-quality award. Clever thinking may be worth 1 XP as stated by
  the source. Do not award monster-kill XP by default.
- Advancement threshold is current level × 10 XP. On leveling, reset XP to
  zero, increase maximum HP by one class hit die, and apply the printed
  talent/title/spell advancement.
- A PC can hold at most one luck token. Spend it to reroll a roll just made
  and use the new result, or give it to a companion.
- In Hard Luck Mode, do not spend a luck token on a critical failure or an
  effect that generates luck. This is applied when the campaign is using
  the Western Reaches GM merge rules.

WESTERN REACHES MODE
- In a Western Reaches campaign, use 02's hex crawl: six-mile hexes; group
  movement; 4/6/8 hexes per day for walking/mounted/sailing, adjusted by
  terrain cost; two encounter checks by day and two overnight at 1:6 each;
  a d12 determines the time of an encounter. Pushing multiplies movement
  by 1.5, adds one extra 1:6 check that day, and prevents foraging.
- Roll daily weather on d6. A 1 is stormy; a 6 is excellent and grants
  advantage on the next weather roll. Apply the region/season climate table.
- In harsh climate, each PC and mount must consume double rations or count
  as having eaten none. Foraging/hunting is DC 18 in normal weather and
  impossible in stormy weather.
- Camping is optional during rest. Each PC may perform one camping task;
  default task DC is 12 unless a task/source gives another value. Resolve
  tasks first, then normal rest and encounter procedures. Without a campfire,
  tasks marked with an asterisk have disadvantage. A campfire costs three
  torches, lasts eight hours while someone stays near it, and lights near.
- Fast travel is allowed only over previously explored hexes. The GM
  estimates time and minimum rations. PCs who cannot eat the minimum arrive
  Drained: CON damage equal to half current CON (round down) and disadvantage
  on all checks and attacks until a successful rest. One PC may attempt the
  source's INT scavenge check using a DC selected from the standard ladder
  according to the region/climate.
- Outside the Western Reaches, retain 01's baseline overland movement/time rules. Encounter checks in this build still follow §5.12: outside Reaches travel, rest, or the darkness trigger, the GM must explicitly trigger a check. This is a labeled encounter-policy override, not the published 01 cadence.
- Do not combine the two travel schedules.

ANTI-DRIFT
Never import:
- bonus actions, combat reactions, legendary actions, free extra PC actions;

- proficiency bonus, expertise arithmetic, saving-throw subsystems, or CR;
- encounter-day pacing, short-rest recharge, or assumptions that a rest is

## 4. Turn loop procedure

1. **Read the state.** Load the current scene, PC sheets, active light, encounter danger, turn phase, NPC positions, conditions, and campaign mode. Reject stale state versions.
2. **Frame the scene.** Describe sensory information the PCs could perceive. Use close/near/far and distinguish visible information from hidden information.
3. **Receive intent.** Ask what the acting PC does. Preserve the player's chosen approach; do not replace it with a different action.
4. **Classify the task.** Determine whether the PC is trained and whether failure could matter. If routine/trained and unpressured, report automatic success without a roll. If uncertain and consequential, proceed.
5. **Choose the resolution.** Name the stat and select Easy 9 / Normal 12 / Hard 15 / Extreme 18. Use a printed fixed DC or formula only where one exists. For an attack, use target AC. For spellcasting, use 10 + tier.
6. **Submit the request.** Send the request to the deterministic layer. It validates state, actor, stat, DC source, action budget, and target. An invalid request is returned for correction, not improvised around.
7. **Resolve the roll.** The engine rolls, applies advantage/disadvantage, natural-1/20 rules, and returns the entire calculation. In contested checks both sides roll; ties reroll.
8. **Resolve the consequence.** The engine applies only mechanical consequences: HP damage, conditions, item use, spell lockout, timer changes, movement, reaction attitude, morale result, or XP award. LLM narration must match the resulting values.
9. **Complete the actor's turn.** At a PC turn start, call `begin_pc_turn`. Before a substantive PC action, call `consume_action` once; the PC attack and spell functions reject calls if that action flag is absent. Apply movement through `move_pc`, never exceeding the turn budget. If no action is taken, permit the source's additional near movement. Do not grant a free second action. Count personal timers at the start of a PC turn.
10. **Complete the GM turn.** Count GM-controlled timers; make only encounter checks due under §5.12 (darkness-triggered crawling, rest cadence, Reaches travel, or an explicit GM trigger); resolve relevant creature/environment movement and actions; describe new information.
11. **Advance the round.** A round ends after all participants have acted and the GM turn is complete. Increment the round and reset turn budgets.
12. **Publish state.** Print every roll, state delta, and the visible state block. End the response with the current situation and the next meaningful choice, not an unsolicited rules lecture.

### Request/response contract

A request is JSON. The exact transport can be a local tool call, a function call, or a line-based bridge; the payload must remain structured.

```json
{
  "request_id": "req-00041",
  "state_version": 17,
  "op": "stat_check",
  "actor_id": "pc-01",
  "stat": "STR",
  "dc": 12,
  "advantage": false,
  "disadvantage": false,
  "reason": "Brace and force the jammed hatch",
  "citation": "01, p. 84"
}
```

An engine result must include the raw dice, selected die, modifier, arithmetic, success/failure, and state version:

```json
{
  "request_id": "req-00041",
  "state_version_before": 17,
  "state_version_after": 18,
  "op": "stat_check",
  "roll": {
    "dice": [11],
    "kept": 11,
    "modifier": 2,
    "total": 13,
    "target": "DC 12",
    "outcome": "success"
  },
  "state_delta": [],
  "state": {}
}
```

A state operation must be explicit too. Examples: `begin_pc_turn`, `consume_action`, `move_pc`, `apply_damage`, `apply_healing`, `consume_item`, `tick_light`, `light_campfire`, `set_campfire_presence`, `reaches_daily_rations`, `reaches_forage`, `set_npc_attitude`, `complete_rest`, `award_treasure_xp`, `reaction_check(npc_id=...)`, and `advance_turn_order`. Before calling `attack` or `cast_spell` for a PC, the action budget must already be consumed. `ignite_torch` is an explicitly labeled adaptation proposal that consumes an action and a torch. Each operation is validated, logged, and returned as a visible delta. Never let the LLM mutate the JSON by writing a replacement state from memory.

**Atomic tool batches.** When a model response proposes multiple operations, treat its `tool_calls` array as one transaction (maximum 16 calls). Validate every tool name, argument name, type, required field, enum, and source-dependent DC before executing any operation. Execute the proposed operations and the host's turn-advancement step against one state snapshot. If validation, any operation, or turn advancement fails, restore the snapshot and discard the entire batch. Persist only after the batch succeeds. Return a structured rollback error; never leave earlier calls from a rejected batch committed.

## 5. Resolution subroutines

### 5.1 Stat check

**Source rule:** Roll 1d20 + relevant stat modifier against a DC. Equality succeeds. Use the four standard DCs. Natural 20 succeeds to maximum capacity; natural 1 fails to maximum capacity. (01, pp. 81, 84)

Procedure:
1. Choose STR, DEX, CON, INT, WIS, or CHA from the actual approach.
2. Apply only source-supported modifiers and advantage/disadvantage.
3. Roll d20. Show `die + modifier = total vs DC`.
4. Natural 20 is automatic maximum success; natural 1 is automatic maximum failure.
5. Apply the stated consequence, if any. Do not invent a consequence merely because a roll failed.

Routine trained work without consequence/time pressure succeeds without a roll. Example: a thief searching the correct area finds a trap; disabling it succeeds if the thief has sufficient time and a reasonable method. (01, pp. 84, 117)

### 5.2 Contested check

**Source rule:** Both participants roll the relevant stat check simultaneously, even if one is not acting. Highest total wins. Reroll ties. (01, p. 84)

Procedure:
- Request both stat rolls in one engine operation.
- Resolve advantage/disadvantage independently for each side.
- Compare totals, not narrative confidence.
- If totals tie, roll both again until they differ.
- Show every tied round and the final comparison.

### 5.3 Advantage and disadvantage

**Source rule:** Roll the same die twice and use the better result for advantage or worse result for disadvantage. If both advantage and disadvantage apply, they cancel. (01, pp. 12, 81)

The engine records both die faces and the kept face. The kept d20 is used for the roll's natural-1/20 check. This “kept die” convention is an **engine policy** that makes the source's keep-better/keep-worse rule deterministic.

### 5.4 Attack

**Source rule:** Melee attack = `1d20 + STR modifier + applicable talent bonuses`; ranged attack = `1d20 + DEX modifier + applicable talent bonuses`. Result equal to or greater than AC hits. Damage is weapon/spell dice plus applicable bonuses. (01, pp. 91–92)

Procedure:
1. Validate that the action is available and target can be seen/targeted.
2. Choose the weapon's legal stat; use finesse or thrown properties only if printed on that weapon.
3. Roll d20 and add stat/talent modifiers.
4. Natural 20 automatically hits and is a critical hit. Natural 1 automatically misses.
5. On hit, roll damage. Subtract from target HP in the engine.
6. If an enemy crosses its morale threshold, perform the morale check.
7. Print attack and damage rolls separately.

### 5.5 Critical hit

- Natural 20 on an attack: automatic hit and critical; double weapon damage dice.
- Natural 20 on a spellcasting check: critical success; double one numerical effect.
- Do not double flat modifiers unless a source rule says so.
- A natural 1 on spellcasting is a critical failure. Wizard: roll the appropriate tier mishap. Priest: penance plus a successful rest. (01, pp. 48–51, 92)
- A natural 1 on an attack automatically misses; the source says it might strike an ally. Do not manufacture an ally hit without a supported adjudication. (01, p. 81)

### 5.6 Spellcasting

**Source rule:** Casting takes the caster's action. Wizard uses INT; priest uses WIS. DC = 10 + spell tier. Success causes the effect. Failure means no effect and the spell is unavailable until rest. (01, pp. 47–48)

```text
spell_dc = 10 + spell_tier
wizard_total = d20 + INT modifier
priest_total = d20 + WIS modifier
```

On natural 1:
- Wizard: roll the mishap table for the spell tier; mark the spell unavailable until successful rest, plus any additional mishap duration/effect. (01, pp. 48–51)
- Priest: mark the spell unavailable. The priest must complete the deity's penance and then a successful rest before casting it again. Penance is determined by the GM based on deity/alignment; it may be a quest, atonement, or material sacrifice. (01, p. 48)

Scrolls and wands also use DC 10 + tier, but their item-specific failure/recovery rules apply. Do not treat them as spell slots. (01, p. 52)

### 5.7 Focus spell

**Source rule:** At the start of the caster's turn, roll a spellcasting check to maintain focus. Success keeps it active until the next turn; failure ends it. Damage or distraction triggers an immediate check. A critical failure is handled as a normal spell critical failure. (01, p. 53)

Procedure:
1. Before the caster acts, request the focus check using the same stat and `10 + tier`.
2. Success: leave focus active until the next check.
3. Failure: end focus. Ordinary focus failure does not make the spell unavailable.
4. Natural 1: apply the spell critical-failure procedure.
5. If damage/distraction occurs between turns, request the immediate check then.

### 5.8 Surprise

**Source rule:** Determine surprise before combat initiative. A creature that starts its turn undetected takes one turn before a new initiative order is rolled. Attacks against surprised targets have advantage. (01, p. 90; 01, p. 91)

Procedure:
- Establish which creatures are actually undetected from the situation and any required stealth/detection checks.
- Resolve one surprise turn for each creature that qualifies.
- Then roll combat initiative: d20 + DEX modifier; highest starts and turn order proceeds clockwise.
- Goblins with the printed Keen Senses trait cannot be surprised. (01, p. 224)

### 5.9 Morale

**Source rule:** When a group is reduced to half its number, or a solo enemy to half HP, it flees if it fails a DC 15 Wisdom check. For large groups, one check uses the leader's modifier. (01, p. 92)

Procedure:
- Trigger once when the threshold is crossed.
- Roll `1d20 + WIS modifier vs DC 15`.
- Success: it does not flee from this check.
- Failure: the affected enemy/group flees.
- Record the check so the engine does not repeat it every turn.

### 5.10 Reaction

**Source rule:** When random creatures appear and their attitude is not already obvious, roll a reaction check. The table uses 2d6 + CHA modifier; a PC who immediately interacts to influence the creatures can apply their CHA modifier. A recognized PC may also gain the applicable Reaches renown bonus. (01, p. 116; 02, p. 232)

| Total | Attitude |
|---:|---|
| 0–6 | Hostile |
| 7–8 | Suspicious |
| 9 | Neutral |
| 10–11 | Curious |
| 12+ | Friendly |

The interaction reveals the PC's presence and position. If attitude is obvious, do not roll. Some creatures, including vicious creatures such as undead, may be automatically hostile. (01, p. 116)

**Reading note:** the core paragraph describes the CHA modifier as available when a PC immediately interacts, while the table labels the roll `2d6 + CHA mod`. This engine uses the table formula when a PC is actively influencing the reaction and plain 2d6 when nobody is doing so. This is an **engine interpretation** of those adjacent statements; record a campaign override if the table prefers a different consistent reading.

### 5.11 Dying and first aid

**Source rule:** At 0 HP, a character is unconscious and dying. Roll `1d4 + CON modifier`, minimum 1, for the death timer. On each subsequent turn, a natural 20 on a d20 brings the character back at 1 HP. First aid at close range is DC 15 INT; success stabilizes the character but leaves them unconscious. (01, p. 92)

Procedure:
1. On reaching 0 HP, set HP to 0 and roll the death timer immediately.
2. On each subsequent dying turn, roll d20. Natural 20: set HP to 1, clear dying, wake the PC.
3. Otherwise decrement the death timer by one round. At zero, set `dead = true`.
4. An intelligent helper at close range can use an action to make a DC 15 INT check. Success clears the timer and sets `stabilized = true`; HP remains 0 and the target remains unconscious.
5. Show the timer, any d20, and stabilization result.

### 5.12 Encounter checks

**Published baseline:** In ordinary crawling, 01 calls for checks every 3 rounds in Unsafe areas, every 2 rounds in Risky areas, and every round in Deadly areas. Roll 1d6; 1 means an encounter. The GM may also check after a loud disturbance. (01, p. 115) For overland travel outside the Reaches, 01 uses the 3/2/1-hour danger cadence. (01, p. 93)

**Active engine policy for this build (user-selected adaptation proposal):** Use this priority exactly:

1. **Crawling + total darkness + at least one active non-dark-adapted PC:** make one 1d6 encounter check every crawling round. Encounter on 1.
2. **Rest:** check every 3 hours (Unsafe), 2 hours (Risky), or 1 hour (Deadly), regardless of light or dark adaptation. Encounter on 1.
3. **Western Reaches travel:** use 02's two 1:6 checks by day and two overnight; pushing adds another 1:6 check. (02, p. 225)
4. **Everything else:** only check when the GM explicitly triggers one. Loud disturbances are a reason the GM may choose to trigger a check, not an automatic extra check.

Darkness alone does not make an area Deadly. If the party is split, test each active PC's `position.in_total_darkness` flag; a check occurs only if at least one active PC is both in darkness and not dark-adapted. The darkness rule applies during crawling only; it does not replace rest or Reaches travel scheduling.

**Departure from published baseline:** item 4 means normal lit crawling and non-Reaches overland travel do not receive automatic danger-cadence checks in this build. This is a deliberate campaign policy override of the published baseline in 01, pp. 93, 115; it must not be represented as the unmodified book rule. If the campaign later switches back to unmodified core play, restore the source's cadence.

If creatures appear, roll 1d6 for starting distance (1 close, 2–4 near, 5–6 far) and 2d6 for activity; resolve reaction using the source procedure. (01, pp. 115–116)

## 6. Resource trackers

### 6.1 Light

- Most light sources last about one hour of real time. Game time passes at the same rate as real time. If the table cannot track real time, one hour can be treated as ten rounds. (01, p. 85)
- Store `remaining_real_minutes` on the active source and tick it using elapsed time supplied by the host. Do not decrement a full hour merely because one player turn ended.
- Outside the illumination area is total darkness. Sight-dependent tasks have disadvantage for creatures that are not dark-adapted. (01, pp. 87–88)
- Under this build's encounter policy, only a crawling round in total darkness with at least one active non-dark-adapted PC forces a check. Otherwise, crawling checks require an explicit GM trigger.
- A campfire made from three torches lasts up to eight hours while a PC remains near and illuminates near. (01, p. 89; 02, p. 229) The engine tracks both remaining hours and whether someone remains near.

### 6.2 Gear slots

`base_limit = max(STR score, 10)`

`effective_limit = base_limit + explicit source-granted slot bonuses`

- Most carried gear uses one slot; hard-to-transport gear can use more. Typical clothing does not use slots. Check each item's printed slot count. (01, pp. 38–39)
- Enforce the limit when an item is acquired, carried, or transferred.
- If a PC is over capacity, do not silently discard or ignore items. Show the conflict and require a choice about what remains carried.
- Example source features may add capacity; apply them only when the class/talent text says so. (01, p. 21; 02, p. 37)

### 6.3 Rations

**Core rest:** every rest requires one ration per PC. (01, p. 89)

**Western Reaches travel:** every PC and mount consumes one ration per day. A PC or mount that does not consume the daily ration takes 1 CON damage; in harsh climate, double rations are required or the PC/mount counts as having consumed none. (02, pp. 225, 227) The deterministic operation `reaches_daily_rations` resolves the daily consumption and CON damage. The rest ration is tracked by `begin_rest` separately; whether one physical ration should satisfy both procedures on the same day is not specified in the source, so this engine does not silently merge them.

**Outside the Reaches:** use 01's baseline overland food/water rule. A PC can go three days without consuming a ration; after that, they take 1 CON damage per day. A PC can forage for one ration/day with an INT check. (01, p. 93)

### 6.4 Rest

A full rest requires:
- one ration per PC;
- eight hours of sleep;
- a DC 12 CON check for each affected PC after each stressful interruption, including combat.

On a failed interruption check, the ration is consumed and that PC gets no benefit from the rest. On a successful rest, restore all lost HP, recover temporary stat damage, and restore abilities whose text says they refresh after rest. (01, p. 89)

In a dangerous area, check for random encounters during rest:
- Unsafe: every 3 hours.
- Risky: every 2 hours.
- Deadly: every 1 hour. (01, p. 89)

A rest interrupted by an encounter is a stressful interruption. Resolve the encounter, request the affected PCs' DC 12 CON checks, and do not fast-forward past the encounter.

### 6.5 Spell availability

Store each known spell as `available`, `failed_until_rest`, or `penance_required`.
- Failed spell: unavailable until a successful rest.
- Wizard natural-1: roll the correct wizard mishap table and apply its additional effects; successful rest is still required.
- Priest natural-1: penance and a successful rest are both required.
- Failed focus maintenance ends focus but does not by itself lock the spell out. A natural-1 focus check is a critical failure. (01, pp. 47–53)

### 6.6 XP and advancement

| Treasure quality | XP per PC |
|---|---:|
| Poor | 0 |
| Normal | 1 |
| Fabulous | 3 |
| Legendary | 10 |

Every PC receives the full award; do not split it. Default XP comes from treasure and boons, not monster kills. The source also lists clever thinking as a possible 1 XP award. (01, p. 120; 02 adaptation framework, §1)

Level threshold = current level × 10 XP. When a PC levels:
- reset XP to zero;
- increase maximum HP by one class hit die;
- apply title, spell, talent, or other improvements shown for the new level;
- grant a talent roll at the levels listed on the advancement table. (01, p. 42)

### 6.7 Luck tokens

- Maximum one per PC.
- Spend one to reroll a roll just made; the new result must be used.
- Or give the token to a companion.
- Do not allow the token to retroactively change a different roll.
- In Western Reaches Hard Luck Mode, do not spend luck on critical failures or effects that generate luck. (01, p. 82; 03, p. 29)

### 6.8 Western Reaches travel, weather, climate, camping, and fast travel

Use these procedures only when the campaign is in the Western Reaches. 03 selects the 02 travel procedure over 01's baseline; it replaces travel movement and encounter schedule, not the core check/combat/rest engine. (02, pp. 225–231; 03, p. 29; assumptions.md, A7)

**Hex movement**
- Hexes are six miles across.
- Group movement/day: walking 4 hexes, mounted 6, sailing 8.
- Normal terrain costs 1 movement point; difficult terrain costs 2; impassable cannot be entered.
- Stormy weather turns normal terrain difficult; in harsh climate, terrain becomes impassable for that day.
- Pushing multiplies daily movement by 1.5, adds another 1:6 encounter chance that day, and prevents foraging. (02, pp. 225–226)

**Encounter checks**
- Two checks during the day and two overnight, each with a 1-in-6 encounter chance.
- Roll a d12 to determine the time of an encounter.
- If pushing, add one extra 1-in-6 check during that day. (02, p. 225)

**Weather and climate**
- Roll d6 daily. A 1 is stormy; a 6 is excellent and grants advantage on the next weather roll.
- Apply the region/season climate table.
- In harsh climate, each PC and mount must consume double rations or be treated as if they consumed none.
- Foraging/hunting in harsh climate is DC 18 in normal weather and impossible in stormy weather.
- When the season changes while PCs are far underground, each must pass DC 12 CHA or take 1d4 CHA damage. (02, pp. 226–228)

**Camping**
- Optional camping takes place during a rest.
- Each PC may perform one task; default task DC is 12.
- Without a campfire, tasks marked with an asterisk have disadvantage.
- Resolve tasks first, then normal rest and encounter checks. (02, p. 229)

| Task | Check | Source effect on success |
|---|---|---|
| Bed Down* | WIS or CON | No check is needed to benefit from rest if sleep is interrupted during this rest |
| Cook* | INT or WIS | Each PC who consumes a ration gains +2 temporary HP for 1 day |
| Craft* | DEX | Create 2d4 mundane ammunition, create one torch, or repair broken mundane gear |
| Entertain* | CHA | Give one luck token to another PC |
| Firewood | STR or CON | Make one free campfire this rest without expending torches |
| Hunt | STR or DEX | Find 1d4 rations; unavailable if the party pushed that day |
| Keep Watch* | WIS | Cannot be surprised during one half of the rest |
| Predict | INT or WIS | After learning tomorrow's weather, force a reroll |

A campfire requires three torches, lasts eight hours while someone remains near, and illuminates near. (02, p. 229)

**Fast travel**
- Only previously explored routes may be used.
- GM estimates journey time based on method, distance, and terrain.
- When a precise number of days is needed, roll 2d6 per estimated week.
- Minimum rations: a few days 1–3; about a week 3; several weeks 3/week.
- PCs unable to eat the required rations arrive Drained: take CON damage equal to half current CON, round down, and have disadvantage on all checks and attack rolls until a successful rest.
- One PC may make an INT scavenge check to avoid arriving Drained; the source says the GM sets DC by region/climate. Use only the standard DC ladder when choosing that DC. (02, p. 230)

### 6.9 Deterministic Python reference layer

This is a compact reference implementation of the engine's critical arithmetic and state transitions. It deliberately leaves narrative-only rulings to the LLM. The host supplies elapsed real minutes and persists the returned state. The source page is cited beside the relevant procedure.

```python
from __future__ import annotations

from copy import deepcopy
from random import Random
from typing import Any


DC_LADDER = {9, 12, 15, 18}
TREASURE_XP = {"poor": 0, "normal": 1, "fabulous": 3, "legendary": 10}
REST_INTERVAL = {"unsafe": 3, "risky": 2, "deadly": 1}
STAT_NAMES = {"STR", "DEX", "CON", "INT", "WIS", "CHA"}


def stat_mod(score: int) -> int:
    # 01, pp. 12, 18: Shadowdark stat score -> modifier table.
    if score <= 3: return -4
    if score <= 5: return -3
    if score <= 7: return -2
    if score <= 9: return -1
    if score <= 11: return 0
    if score <= 13: return 1
    if score <= 15: return 2
    if score <= 17: return 3
    return 4


class ShadowdarkEngine:
    def __init__(self, state: dict[str, Any], seed: int | None = None):
        self.state = deepcopy(state)
        self.rng = Random(seed)
        self.state.setdefault("state_version", 0)
        self.state.setdefault("event_log", [])

    def _pc(self, actor_id: str) -> dict[str, Any]:
        for pc in self.state["pcs"]:
            if pc["id"] == actor_id:
                return pc
        raise KeyError(f"Unknown PC: {actor_id}")

    def _npc(self, actor_id: str) -> dict[str, Any]:
        for npc in self.state.get("npcs", []):
            if npc["id"] == actor_id:
                return npc
        raise KeyError(f"Unknown NPC: {actor_id}")

    def _mount(self, mount_id: str) -> dict[str, Any]:
        for mount in self.state.get("mounts", []):
            if mount["id"] == mount_id:
                return mount
        raise KeyError(f"Unknown mount: {mount_id}")

    def _consume_pc_rations(self, pc: dict[str, Any], amount: int) -> bool:
        gear = pc["gear"]
        if gear.get("rations_count", 0) < amount:
            return False
        remaining = amount
        for item in gear.get("items", []):
            if item.get("name", "").lower() != "ration":
                continue
            if "units_remaining" in item:
                available = item["units_remaining"]
                used = min(remaining, available)
                item["units_remaining"] -= used
                remaining -= used
                if item["units_remaining"] == 0:
                    item["quantity"] = max(0, item.get("quantity", 1) - 1)
            else:
                used = min(remaining, item.get("quantity", 0))
                item["quantity"] -= used
                remaining -= used
            if remaining == 0:
                break
        if remaining:
            raise ValueError("rations_count and carried ration items are out of sync")
        gear["rations_count"] -= amount
        return True

    def _actor(self, actor_id: str) -> dict[str, Any]:
        for actor in self.state["pcs"] + self.state.get("npcs", []):
            if actor["id"] == actor_id:
                return actor
        raise KeyError(f"Unknown actor: {actor_id}")

    @staticmethod
    def _is_pc(actor: dict[str, Any]) -> bool:
        return "hp" in actor and "gear" in actor and "level" in actor

    def _stat_modifier(self, actor: dict[str, Any], stat: str) -> int:
        # PCs store stat scores; NPC stat blocks store modifiers. (01, pp. 18, 194–196)
        if self._is_pc(actor):
            return stat_mod(actor["stats"][stat]) - actor.get("stat_damage", {}).get(stat, 0)
        return actor.get("stats", {}).get(stat, 0)

    def _commit(self, kind: str, detail: dict[str, Any]) -> dict[str, Any]:
        self.state["state_version"] += 1
        event = {
            "version": self.state["state_version"],
            "kind": kind,
            "detail": deepcopy(detail)
        }
        self.state["event_log"].append(event)
        return {
            "event": event,
            "state_version": self.state["state_version"],
            "state": deepcopy(self.state)
        }

    def die(self, sides: int) -> int:
        if sides < 2:
            raise ValueError("A die must have at least 2 sides")
        return self.rng.randint(1, sides)

    def dice(self, count: int, sides: int) -> dict[str, Any]:
        if count < 1:
            raise ValueError("Dice count must be positive")
        faces = [self.die(sides) for _ in range(count)]
        return {"expression": f"{count}d{sides}", "faces": faces, "total": sum(faces)}

    def d20(self, modifier: int = 0, advantage: bool = False,
            disadvantage: bool = False) -> dict[str, Any]:
        # 01, pp. 12, 81: roll twice for advantage/disadvantage; they cancel.
        if advantage and disadvantage:
            advantage = disadvantage = False
        faces = [self.die(20), self.die(20)] if (advantage or disadvantage) else [self.die(20)]
        kept = max(faces) if advantage else min(faces) if disadvantage else faces[0]
        return {
            "die": "d20",
            "faces": faces,
            "kept": kept,
            "modifier": modifier,
            "total": kept + modifier,
            "natural_20": kept == 20,
            "natural_1": kept == 1,
            "advantage": advantage,
            "disadvantage": disadvantage
        }

    def _check(self, actor_id: str, stat: str, dc: int,
               advantage: bool = False, disadvantage: bool = False,
               dc_source: str | None = None) -> dict[str, Any]:
        # 01, p. 84: standard DCs. Source-specific fixed DCs/formulas need a citation.
        if stat not in STAT_NAMES:
            raise ValueError(f"Invalid stat: {stat}")
        if dc not in DC_LADDER and not dc_source:
            raise ValueError("Nonstandard DC requires a source citation")
        actor = self._actor(actor_id)
        modifier = self._stat_modifier(actor, stat)
        roll = self.d20(modifier, advantage, disadvantage)
        success = True if roll["natural_20"] else False if roll["natural_1"] else roll["total"] >= dc
        return {
            "actor_id": actor_id,
            "stat": stat,
            "roll": roll,
            "target": f"DC {dc}",
            "success": success,
            "outcome": "success" if success else "failure"
        }

    def stat_check(self, actor_id: str, stat: str, dc: int,
                   advantage: bool = False, disadvantage: bool = False,
                   routine_trained: bool = False,
                   dc_source: str | None = None) -> dict[str, Any]:
        # 01, p. 84: routine trained tasks succeed without a roll.
        if routine_trained:
            result = {
                "actor_id": actor_id, "stat": stat, "roll": None,
                "target": f"DC {dc}", "success": True,
                "outcome": "automatic success: routine trained task"
            }
        else:
            result = self._check(actor_id, stat, dc, advantage, disadvantage, dc_source)
        committed = self._commit("stat_check", result)
        return {"result": result, **committed}

    def contested_check(self, a_id: str, a_stat: str, b_id: str, b_stat: str,
                        a_adv: bool = False, a_dis: bool = False,
                        b_adv: bool = False, b_dis: bool = False) -> dict[str, Any]:
        # 01, p. 84: simultaneous checks; highest total wins; reroll ties.
        rounds = []
        while True:
            a = self._check(a_id, a_stat, 0, a_adv, a_dis, "contested check")
            b = self._check(b_id, b_stat, 0, b_adv, b_dis, "contested check")
            rounds.append({"a": a, "b": b})
            if a["roll"]["total"] != b["roll"]["total"]:
                winner = a_id if a["roll"]["total"] > b["roll"]["total"] else b_id
                break
        result = {"rounds": rounds, "winner": winner}
        committed = self._commit("contested_check", result)
        return {"result": result, **committed}

    def apply_damage(self, target_id: str, amount: int, cause: str,
                     source_id: str | None = None) -> dict[str, Any]:
        # 01, pp. 12, 92: damage reduces HP; 0 HP starts the dying procedure.
        if amount < 0:
            raise ValueError("Damage cannot be negative")
        target = self._actor(target_id)
        if self._is_pc(target):
            temporary = target["hp"].get("temporary", 0)
            absorbed = min(temporary, amount)
            target["hp"]["temporary"] = temporary - absorbed
            hp_damage = amount - absorbed
            target["hp"]["current"] = max(0, target["hp"]["current"] - hp_damage)
            dying = None
            if target["hp"]["current"] == 0 and not target["hp"].get("dying"):
                dying = self._start_dying_state(target_id)
            hp_after = target["hp"]["current"]
        else:
            absorbed = 0
            dying = None
            target["hp_current"] = max(0, target.get("hp_current", 0) - amount)
            hp_after = target["hp_current"]
        result = {"target_id": target_id, "source_id": source_id,
                  "cause": cause, "damage": amount,
                  "temporary_hp_absorbed": absorbed,
                  "hp_after": hp_after, "dying_timer": dying}
        committed = self._commit("damage_applied", result)
        morale = None
        if not self._is_pc(target):
            solo_at_half = (target.get("is_solo", True)
                            and target.get("hp_maximum", 0) > 0
                            and target.get("hp_current", 0) * 2 <= target["hp_maximum"])
            group_at_half = (not target.get("is_solo", True)
                             and target.get("initial_number", 0) > 0
                             and target.get("current_number", 0) * 2 <= target["initial_number"])
            if solo_at_half or group_at_half:
                morale = self.morale_check(target_id)
        return {"result": result, "morale": morale,
                "event": committed["event"],
                "state_version": self.state["state_version"],
                "state": self.visible_state()}

    def apply_healing(self, target_id: str, amount: int, cause: str) -> dict[str, Any]:
        # 01, p. 92: a creature that rises above 0 HP is no longer dying.
        if amount < 0:
            raise ValueError("Healing cannot be negative")
        target = self._actor(target_id)
        if self._is_pc(target):
            if target["hp"].get("dead"):
                raise ValueError("A dead PC is retired; this engine does not infer resurrection")
            before = target["hp"]["current"]
            target["hp"]["current"] = min(target["hp"]["maximum"], before + amount)
            if target["hp"]["current"] > 0:
                target["hp"].update({"dying": False, "stabilized": False,
                                     "death_rounds_remaining": None})
            after = target["hp"]["current"]
        else:
            before = target.get("hp_current", 0)
            target["hp_current"] = min(target.get("hp_maximum", before), before + amount)
            after = target["hp_current"]
        result = {"target_id": target_id, "cause": cause,
                  "healing": amount, "hp_before": before, "hp_after": after}
        return {"result": result, **self._commit("healing_applied", result)}

    def attack(self, attacker_id: str, target_id: str, kind: str,
               damage_count: int, damage_sides: int, attack_bonus: int = 0,
               damage_bonus: int = 0, talent_bonus: int = 0,
               advantage: bool = False, disadvantage: bool = False,
               stat: str | None = None) -> dict[str, Any]:
        # 01, pp. 91–92: melee STR, ranged DEX; compare total to AC.
        attacker = self._actor(attacker_id)
        target = self._actor(target_id)
        if self._is_pc(attacker) and not attacker["turn_budget"].get("action_used"):
            raise ValueError("Call consume_action before a PC attack")
        if kind not in {"melee", "ranged"}:
            raise ValueError("Attack kind must be melee or ranged")
        attack_stat = stat or ("STR" if kind == "melee" else "DEX")
        if self._is_pc(attacker):
            # PC: add the linked stat modifier and applicable talent bonuses.
            modifier = self._stat_modifier(attacker, attack_stat)
            total_modifier = modifier + attack_bonus + talent_bonus
        else:
            # Monster stat-block ATK +X is already the complete attack bonus.
            total_modifier = attack_bonus + talent_bonus
        roll = self.d20(total_modifier, advantage, disadvantage)
        if "ac" not in target:
            raise ValueError(f"Target {target_id} has no AC in state")
        ac = target["ac"]
        hit = roll["natural_20"] or (not roll["natural_1"] and roll["total"] >= ac)
        damage = None
        dying_result = None
        if hit:
            # 01, p. 92: critical weapon hit doubles the damage dice, not flat bonuses.
            count = damage_count * (2 if roll["natural_20"] else 1)
            damage_roll = self.dice(count, damage_sides)
            damage_total = damage_roll["total"] + damage_bonus
            damage = {
                "dice": damage_roll,
                "flat_bonus": damage_bonus,
                "total": damage_total,
                "critical": roll["natural_20"]
            }
            if self._is_pc(target):
                target["hp"]["current"] = max(0, target["hp"]["current"] - damage_total)
                if target["hp"]["current"] == 0 and not target["hp"].get("dying"):
                    dying_result = self._start_dying_state(target_id)
            else:
                target["hp_current"] = max(0, target.get("hp_current", 0) - damage_total)
        result = {
            "attacker_id": attacker_id,
            "target_id": target_id,
            "roll": roll,
            "target_ac": ac,
            "hit": hit,
            "damage": damage,
            "dying_timer": dying_result
        }
        committed = self._commit("attack", result)
        morale = None
        if hit and not self._is_pc(target):
            solo_at_half = (target.get("is_solo", True)
                            and target.get("hp_maximum", 0) > 0
                            and target.get("hp_current", 0) * 2 <= target["hp_maximum"])
            group_at_half = (not target.get("is_solo", True)
                             and target.get("initial_number", 0) > 0
                             and target.get("current_number", 0) * 2 <= target["initial_number"])
            if solo_at_half or group_at_half:
                morale = self.morale_check(target_id)
        return {"result": result, "morale": morale,
                "event": committed["event"],
                "state_version": self.state["state_version"],
                "state": self.visible_state()}

    def set_npc_attitude(self, npc_id: str, attitude: str) -> dict[str, Any]:
        # 01, p. 116: persist the attitude produced by a reaction check or fiction.
        allowed = {"hostile", "suspicious", "neutral", "curious", "friendly"}
        if attitude not in allowed:
            raise ValueError("Unknown NPC attitude")
        npc = self._npc(npc_id)
        before = npc.get("attitude")
        npc["attitude"] = attitude
        result = {"npc_id": npc_id, "old_attitude": before,
                  "new_attitude": attitude}
        return {"result": result, **self._commit("npc_attitude_changed", result)}

    def set_group_numbers(self, npc_id: str, current_number: int,
                          leader_modifier: int | None = None) -> dict[str, Any]:
        """Record surviving members; source gives morale trigger, not casualty math."""
        npc = self._npc(npc_id)
        if npc.get("is_solo", True):
            raise ValueError("Use HP damage for a solo creature")
        if not 0 <= current_number <= npc.get("initial_number", 0):
            raise ValueError("Current group count must be within the initial count")
        npc["current_number"] = current_number
        result = {"npc_id": npc_id, "current_number": current_number,
                  "initial_number": npc["initial_number"]}
        committed = self._commit("group_count_changed", result)
        morale = self.morale_check(npc_id, leader_modifier) if (
            current_number * 2 <= npc["initial_number"]
        ) else None
        return {"result": result, "morale": morale,
                "event": self.state["event_log"][-1],
                "state_version": self.state["state_version"],
                "state": self.visible_state()}

    def morale_check(self, npc_id: str, leader_modifier: int | None = None) -> dict[str, Any]:
        # 01, p. 92: DC 15 WIS at half numbers or solo half HP; failure flees.
        npc = self._npc(npc_id)
        if npc.get("morale_checked") or npc.get("fled"):
            return {"skipped": "morale already resolved"}
        solo_at_half = (npc.get("is_solo", True)
                        and npc.get("hp_maximum", 0) > 0
                        and npc.get("hp_current", 0) * 2 <= npc["hp_maximum"])
        group_at_half = (not npc.get("is_solo", True)
                         and npc.get("initial_number", 0) > 0
                         and npc.get("current_number", 0) * 2 <= npc["initial_number"])
        if not (solo_at_half or group_at_half):
            return {"skipped": "morale threshold not reached"}
        wis = leader_modifier if leader_modifier is not None else npc.get("stats", {}).get("WIS", 0)
        roll = self.d20(wis)
        success = True if roll["natural_20"] else False if roll["natural_1"] else roll["total"] >= 15
        npc["morale_checked"] = True
        if not success:
            npc["fled"] = True
        result = {"npc_id": npc_id, "roll": roll, "target": "DC 15 WIS",
                  "success": success, "fled": not success}
        return {"result": result, **self._commit("morale", result)}

    def reaction_check(self, pc_id: str | None, recognized: bool = False,
                       creature_always_hostile: bool = False,
                       npc_id: str | None = None) -> dict[str, Any]:
        # 01, p. 116: reaction table. 02, p. 232: recognized renown bonus.
        if creature_always_hostile:
            result = {"total": None, "attitude": "hostile", "automatic": True}
        else:
            dice = self.dice(2, 6)
            cha = 0
            renown_bonus = 0
            if pc_id is not None:
                pc = self._pc(pc_id)
                cha = stat_mod(pc["stats"]["CHA"])
                if recognized:
                    r = pc.get("renown", cha)
                    renown_bonus = 0 if r <= 3 else 1 if r <= 7 else 2 if r <= 11 else 3
            total = dice["total"] + cha + renown_bonus
            attitude = (
                "hostile" if total <= 6 else
                "suspicious" if total <= 8 else
                "neutral" if total == 9 else
                "curious" if total <= 11 else
                "friendly"
            )
            result = {
                "dice": dice, "cha_modifier": cha,
                "renown_bonus": renown_bonus, "total": total,
                "attitude": attitude, "automatic": False
            }
        if npc_id is not None:
            self._npc(npc_id)["attitude"] = result["attitude"]
            result["npc_id"] = npc_id
        return {"result": result, **self._commit("reaction_check", result)}

    def begin_pc_turn(self, pc_id: str) -> dict[str, Any]:
        # 01, p. 86: personal timers then one action + near movement.
        pc = self._pc(pc_id)
        pc["turn_budget"].update({"action_used": False, "movement_used": "none",
                                  "near_moves_used": 0})
        result = {"pc_id": pc_id, "turn_budget": deepcopy(pc["turn_budget"])}
        return {"result": result, **self._commit("pc_turn_started", result)}

    def consume_action(self, pc_id: str, action_name: str) -> dict[str, Any]:
        # 01, pp. 86, 91: one action per PC turn; no extra action economy.
        pc = self._pc(pc_id)
        budget = pc["turn_budget"]
        if budget.get("action_used"):
            raise ValueError("This PC has already used its action this turn")
        budget["action_used"] = True
        result = {"pc_id": pc_id, "action": action_name, "action_used": True}
        return {"result": result, **self._commit("pc_action_used", result)}

    def move_pc(self, pc_id: str, destination_id: str,
                distance: str = "near") -> dict[str, Any]:
        # 01, pp. 86, 88: one near move with an action; another near move if no action.
        if distance not in {"close", "near"}:
            raise ValueError("PC movement is limited to close/near; far is not a movement unit")
        pc = self._pc(pc_id)
        budget = pc["turn_budget"]
        max_moves = 1 if budget.get("action_used") else 2
        if budget.get("near_moves_used", 0) >= max_moves:
            raise ValueError("Near movement budget exceeded for this turn")
        budget["near_moves_used"] = budget.get("near_moves_used", 0) + 1
        budget["movement_used"] = distance
        pc["position"]["location_id"] = destination_id
        result = {"pc_id": pc_id, "destination_id": destination_id,
                  "distance": distance, "near_moves_used": budget["near_moves_used"],
                  "maximum_near_moves": max_moves}
        return {"result": result, **self._commit("pc_moved", result)}

    def initiative(self, actor_ids: list[str]) -> dict[str, Any]:
        # 01, pp. 86, 91: d20 + DEX; highest begins; clockwise order thereafter.
        entries = []
        for actor_id in actor_ids:
            actor = self._actor(actor_id)
            dex = self._stat_modifier(actor, "DEX")
            roll = self.d20(dex)
            entries.append({"actor_id": actor_id, "roll": roll})
        # Stable ordering preserves the supplied clockwise order for exact ties.
        entries.sort(key=lambda e: e["roll"]["total"], reverse=True)
        self.state["campaign"]["turn_order"]["initiative_results"] = entries
        self.state["campaign"]["turn_order"]["order"] = [e["actor_id"] for e in entries]
        self.state["campaign"]["turn_order"]["turn_index"] = 0
        self.state["campaign"]["turn_order"]["active_actor_id"] = (
            self.state["campaign"]["turn_order"]["order"][0]
            if self.state["campaign"]["turn_order"]["order"] else None
        )
        result = {"initiative": entries, "order": self.state["campaign"]["turn_order"]["order"]}
        return {"result": result, **self._commit("initiative", result)}

    def set_surprise_queue(self, undetected_actor_ids: list[str]) -> dict[str, Any]:
        # 01, p. 90–91: undetected creatures take one turn before initiative.
        self.state["campaign"]["turn_order"]["surprise_queue"] = list(undetected_actor_ids)
        result = {"surprise_turns_before_initiative": list(undetected_actor_ids)}
        return {"result": result, **self._commit("surprise", result)}

    def cast_spell(self, pc_id: str, spell_name: str, tier: int,
                   caster_kind: str, mishap_die_sides: int = 12) -> dict[str, Any]:
        # 01, pp. 47–51: casting action; wizard INT / priest WIS; DC 10 + tier.
        pc = self._pc(pc_id)
        if not pc["turn_budget"].get("action_used"):
            raise ValueError("Call consume_action before casting a spell")
        spells = pc["spells"]
        if spell_name not in spells.get("available", []):
            raise ValueError(f"{spell_name} is not currently available")
        stat = "INT" if caster_kind == "wizard" else "WIS"
        dc = 10 + tier
        result = self._check(pc_id, stat, dc, dc_source=f"spell DC 10 + tier ({tier})")
        natural_1 = result["roll"]["natural_1"]
        if result["success"]:
            outcome = "spell takes effect"
            if result["roll"]["natural_20"]:
                outcome = "critical success: double one numerical effect"
        else:
            spells["available"].remove(spell_name)
            spells.setdefault("unavailable_until_rest", []).append(spell_name)
            outcome = "failed: no effect; unavailable until successful rest"
            if natural_1:
                if caster_kind == "wizard":
                    mishap_roll = self.die(mishap_die_sides)
                    spells.setdefault("mishap_pending", []).append(
                        {"spell": spell_name, "tier": tier, "roll": mishap_roll}
                    )
                    outcome = f"critical failure: wizard mishap table roll {mishap_roll}; unavailable until rest"
                elif caster_kind == "priest":
                    spells.setdefault("penance_required", []).append(spell_name)
                    outcome = "critical failure: penance and successful rest required"
        result.update({"spell": spell_name, "tier": tier, "caster_kind": caster_kind,
                       "target": f"DC {dc}", "outcome": outcome})
        return {"result": result, **self._commit("spellcasting", result)}

    def maintain_focus(self, pc_id: str, spell_name: str, tier: int,
                       caster_kind: str) -> dict[str, Any]:
        # 01, p. 53: focus check at start of turn and immediately after damage/distraction.
        pc = self._pc(pc_id)
        stat = "INT" if caster_kind == "wizard" else "WIS"
        result = self._check(pc_id, stat, 10 + tier,
                             dc_source=f"focus spell DC 10 + tier ({tier})")
        if not result["success"]:
            pc["spells"]["focus"] = None
            result["focus_ended"] = True
            if result["roll"]["natural_1"]:
                result["critical_failure"] = True
                # Standard critical-failure lockout applies to focus spells too.
                if spell_name in pc["spells"].get("available", []):
                    pc["spells"]["available"].remove(spell_name)
                unavailable = pc["spells"].setdefault("unavailable_until_rest", [])
                if spell_name not in unavailable:
                    unavailable.append(spell_name)
                if caster_kind == "wizard":
                    mishap_roll = self.die(12)
                    pc["spells"].setdefault("mishap_pending", []).append(
                        {"spell": spell_name, "tier": tier, "roll": mishap_roll}
                    )
                else:
                    penance = pc["spells"].setdefault("penance_required", [])
                    if spell_name not in penance:
                        penance.append(spell_name)
        else:
            pc["spells"]["focus"] = {
                "spell": spell_name, "tier": tier, "until": "start_of_next_turn"
            }
            result["focus_maintained"] = True
        return {"result": result, **self._commit("focus_check", result)}

    def _start_dying_state(self, pc_id: str) -> dict[str, Any]:
        # Internal mutation helper; caller controls the single visible commit.
        pc = self._pc(pc_id)
        con = self._stat_modifier(pc, "CON")
        die = self.die(4)
        rounds = max(1, die + con)
        pc["hp"]["current"] = 0
        pc["hp"]["dying"] = True
        pc["hp"]["stabilized"] = False
        pc["hp"]["death_rounds_remaining"] = rounds
        return {"pc_id": pc_id, "roll": f"1d4({die}) + CON({con})",
                "death_rounds": rounds}

    def start_dying(self, pc_id: str) -> dict[str, Any]:
        # 01, p. 92: 1d4 + CON modifier, minimum 1 round.
        pc = self._pc(pc_id)
        if pc["hp"]["current"] > 0:
            raise ValueError("A PC only begins dying at 0 HP")
        result = self._start_dying_state(pc_id)
        return {"result": result, **self._commit("dying_started", result)}

    def dying_turn(self, pc_id: str) -> dict[str, Any]:
        # 01, p. 92: on each subsequent turn, natural 20 returns the PC at 1 HP.
        pc = self._pc(pc_id)
        if not pc["hp"].get("dying") or pc["hp"].get("stabilized"):
            raise ValueError("PC is not actively dying")
        roll = self.d20()
        if roll["natural_20"]:
            pc["hp"].update({"current": 1, "dying": False,
                             "death_rounds_remaining": None})
            outcome = "returns at 1 HP"
        else:
            pc["hp"]["death_rounds_remaining"] -= 1
            if pc["hp"]["death_rounds_remaining"] <= 0:
                pc["hp"].update({"dying": False, "dead": True,
                                 "death_rounds_remaining": 0})
                outcome = "dies"
            else:
                outcome = "still dying"
        result = {"pc_id": pc_id, "roll": roll, "outcome": outcome,
                  "timer": pc["hp"]["death_rounds_remaining"]}
        return {"result": result, **self._commit("dying_turn", result)}

    def first_aid(self, helper_id: str, target_id: str,
                  target_distance: str = "close") -> dict[str, Any]:
        # 01, p. 92: close-range first aid is DC 15 INT.
        if target_distance != "close":
            raise ValueError("First aid requires close range")
        target = self._pc(target_id)
        if not target["hp"].get("dying"):
            raise ValueError("Target is not dying")
        result = self._check(helper_id, "INT", 15)
        if result["success"]:
            target["hp"]["dying"] = False
            target["hp"]["stabilized"] = True
            target["hp"]["death_rounds_remaining"] = None
        result.update({"target_id": target_id, "stabilized": result["success"]})
        return {"result": result, **self._commit("first_aid", result)}

    def _tick_light_state(self, elapsed_real_minutes: int) -> dict[str, Any]:
        """Mutate elapsed-time and light counters without creating a nested commit."""
        light = self.state["campaign"]["light"]
        if light.get("lit"):
            light["remaining_real_minutes"] = max(
                0, light["remaining_real_minutes"] - elapsed_real_minutes
            )
            if light["remaining_real_minutes"] == 0:
                light["lit"] = False
                light["active_source_id"] = None
                light["source_type"] = None
        # Already-lit backup sources burn in real time too.
        for source in light.get("backup_sources", []):
            if source.get("lit"):
                source["remaining_real_minutes"] = max(
                    0, source.get("remaining_real_minutes", 0) - elapsed_real_minutes
                )
                if source["remaining_real_minutes"] == 0:
                    source["lit"] = False
        backups = [source for source in light.get("backup_sources", []) if source.get("lit")]
        if not light.get("lit") and backups:
            promoted = backups.pop(0)
            light.update({
                "active_source_id": promoted.get("id"),
                "source_type": promoted.get("source_type"),
                "lit": True,
                "remaining_real_minutes": promoted.get("remaining_real_minutes", 0),
                "illumination_distance": promoted.get("illumination_distance", "near")
            })
        light["backup_sources"] = [source for source in light.get("backup_sources", [])
                                   if source.get("lit")]
        campfire = light.get("campfire", {})
        if campfire.get("lit"):
            elapsed_hours = elapsed_real_minutes / 60
            campfire["remaining_hours"] = max(0, campfire.get("remaining_hours", 0) - elapsed_hours)
            if (campfire["remaining_hours"] == 0
                    or (campfire.get("requires_character_nearby", True)
                        and not campfire.get("someone_nearby", True))):
                campfire["lit"] = False
        active = (light.get("lit", False) or bool(light.get("backup_sources"))
                  or campfire.get("lit", False)
                  or self.state["campaign"]["environment"].get("ambient_light", False))
        self.state["campaign"]["environment"]["total_darkness"] = not active
        self.state["campaign"]["clock"]["real_elapsed_minutes"] += elapsed_real_minutes
        return {
            "elapsed_real_minutes": elapsed_real_minutes,
            "light": deepcopy(light),
            "total_darkness": self.state["campaign"]["environment"]["total_darkness"]
        }

    def light_campfire(self, pc_id: str, torch_item_name: str = "torch") -> dict[str, Any]:
        # 01, p. 89; 02, p. 229: three torches, eight hours, near illumination.
        pc = self._pc(pc_id)
        if not pc.get("position", {}).get("near_campfire_site", True):
            raise ValueError("PC is not at the campfire location")
        torch_item = next((x for x in pc["gear"]["items"]
                           if x["name"].lower() == torch_item_name.lower()
                           and x.get("quantity", 0) >= 3), None)
        if torch_item is None:
            raise ValueError("Three carried torches are required")
        campfire = self.state["campaign"]["light"]["campfire"]
        if campfire.get("lit"):
            raise ValueError("Campfire is already lit")
        torch_item["quantity"] -= 3
        campfire.update({"lit": True, "remaining_hours": 8,
                         "requires_character_nearby": True, "someone_nearby": True})
        self.state["campaign"]["environment"]["total_darkness"] = False
        result = {"pc_id": pc_id, "torches_consumed": 3,
                  "campfire": deepcopy(campfire)}
        return {"result": result, **self._commit("campfire_lit", result)}

    def set_campfire_presence(self, someone_nearby: bool) -> dict[str, Any]:
        campfire = self.state["campaign"]["light"]["campfire"]
        campfire["someone_nearby"] = bool(someone_nearby)
        result = {"someone_nearby": campfire["someone_nearby"]}
        return {"result": result, **self._commit("campfire_presence", result)}

    def ignite_torch(self, pc_id: str, torch_item_name: str = "torch") -> dict[str, Any]:
        # ADAPTATION PROPOSAL: lighting a torch is treated as one action in this host.
        pc = self._pc(pc_id)
        budget = pc["turn_budget"]
        if budget.get("action_used"):
            raise ValueError("Lighting a torch requires the unused action in this turn")
        item = next((x for x in pc["gear"]["items"]
                     if x["name"].lower() == torch_item_name.lower()
                     and x.get("quantity", 0) > 0), None)
        if item is None:
            raise ValueError("No carried torch available")
        item["quantity"] -= 1
        budget["action_used"] = True
        light = self.state["campaign"]["light"]
        if light.get("lit") and light.get("active_source_id"):
            light.setdefault("backup_sources", []).append({
                "id": light["active_source_id"],
                "source_type": light.get("source_type"),
                "lit": True,
                "remaining_real_minutes": light["remaining_real_minutes"],
                "illumination_distance": light.get("illumination_distance", "near")
            })
        light.update({"active_source_id": item.get("id", "new-torch"),
                      "source_type": "torch", "lit": True,
                      "remaining_real_minutes": 60,
                      "illumination_distance": "near"})
        env = self.state["campaign"]["environment"]
        env["total_darkness"] = False
        result = {"pc_id": pc_id, "action": "light torch",
                  "item_remaining": item["quantity"],
                  "light": deepcopy(light), "total_darkness": False}
        return {"result": result, **self._commit("torch_lit", result)}

    def tick_light(self, elapsed_real_minutes: int) -> dict[str, Any]:
        # 01, p. 85: most light sources last one real-time hour.
        if elapsed_real_minutes < 0:
            raise ValueError("Elapsed time cannot be negative")
        result = self._tick_light_state(elapsed_real_minutes)
        return {"result": result, **self._commit("light_tick", result)}

    def encounter_check(self, phase: str = "crawling",
                        gm_triggered: bool = False,
                        loud_disturbance: bool = False) -> dict[str, Any]:
        # User-selected engine policy: only darkness-triggered crawling checks
        # and explicit GM-triggered checks use this operation. Rest and Reaches
        # travel have dedicated deterministic schedulers below.
        # Published baseline: 01, pp. 93, 115; build override: §5.12.
        env = self.state["campaign"]["environment"]
        clock = self.state["campaign"]["encounter_clock"]

        if phase == "rest":
            raise ValueError("Use advance_rest(); it enforces the 3/2/1-hour danger cadence")
        if phase in {"reaches", "reaches_day", "reaches_overnight"}:
            raise ValueError("Use reaches_encounters(); it enforces 2 day + 2 overnight 1:6 checks")

        active_pcs = [pc for pc in self.state.get("pcs", [])
                      if not pc.get("hp", {}).get("dead", False)]
        non_dark_adapted_in_darkness = any(
            not pc.get("dark_adapted", False)
            and pc.get("position", {}).get("in_total_darkness", env.get("total_darkness", False))
            for pc in active_pcs
        )
        darkness_forced = (
            phase == "crawling"
            and non_dark_adapted_in_darkness
            and clock.get("darkness_forces_every_round_for_non_dark_adapted_pcs", True)
        )
        gm_trigger = gm_triggered or loud_disturbance
        if not darkness_forced and not gm_trigger:
            return {"result": {
                "checked": False,
                "phase": phase,
                "reason": "no darkness trigger and no explicit GM trigger",
                "non_dark_adapted_in_darkness": non_dark_adapted_in_darkness,
                "total_darkness": env.get("total_darkness", False)
            }}

        die = self.die(6)
        trigger = ("darkness: crawling round with non-dark-adapted PC"
                   if darkness_forced else
                   "loud disturbance" if loud_disturbance else "explicit GM trigger")
        clock["crawling_rounds_since_check"] = 0
        result = {
            "checked": True,
            "phase": phase,
            "die": die,
            "encounter": die == 1,
            "trigger": trigger,
            "non_dark_adapted_in_darkness": non_dark_adapted_in_darkness
        }
        clock["last_roll"] = die
        clock["last_result"] = result["encounter"]
        clock["last_trigger"] = trigger
        return {"result": result, **self._commit("encounter_check", result)}

    def begin_rest(self, pc_ids: list[str]) -> dict[str, Any]:
        # 01, p. 89: one ration and eight hours' sleep per PC.
        rest = self.state["campaign"]["rest"]
        if rest.get("active"):
            raise ValueError("A rest is already active")
        consumed = {}
        for pc_id in pc_ids:
            pc = self._pc(pc_id)
            if not self._consume_pc_rations(pc, 1):
                raise ValueError(f"{pc['name']} has no ration")
            consumed[pc_id] = 1
        rest.update({
            "active": True, "hours_elapsed": 0, "pc_ids": list(pc_ids),
            "rations_consumed": consumed, "failed_pc_ids": [],
            "interruption_checks": [], "encounter_pending": False,
            "completed": False
        })
        return {"result": {"rest_started": True, "rations_consumed": consumed},
                **self._commit("rest_started", {"pc_ids": pc_ids, "consumed": consumed})}

    def rest_interruption(self, affected_pc_ids: list[str]) -> dict[str, Any]:
        # 01, p. 89: each stressful interruption requires DC 12 CON.
        rest = self.state["campaign"]["rest"]
        if not rest.get("active"):
            raise ValueError("No active rest")
        results = []
        for pc_id in affected_pc_ids:
            result = self._check(pc_id, "CON", 12)
            rest["interruption_checks"].append({"pc_id": pc_id, **result})
            if not result["success"] and pc_id not in rest["failed_pc_ids"]:
                rest["failed_pc_ids"].append(pc_id)
            results.append({"pc_id": pc_id, **result})
        return {"result": results, **self._commit("rest_interruption", {"checks": results})}

    def advance_rest(self, hours: int) -> dict[str, Any]:
        # 01, p. 89: danger-level encounter cadence during rest.
        rest = self.state["campaign"]["rest"]
        if not rest.get("active") or hours < 0:
            raise ValueError("No active rest or invalid hours")
        env = self.state["campaign"]["environment"]
        interval = REST_INTERVAL[env["danger_level"]]
        checks = []
        if rest.get("encounter_pending"):
            raise ValueError("Resolve the pending rest encounter before advancing time")
        actual_advanced = 0
        light_ticks = []
        for _ in range(hours):
            rest["hours_elapsed"] += 1
            actual_advanced += 1
            light_ticks.append(self._tick_light_state(60))
            if rest["hours_elapsed"] % interval == 0:
                die = self.die(6)
                check = {"hour": rest["hours_elapsed"], "die": die, "encounter": die == 1}
                checks.append(check)
                if die == 1:
                    rest["encounter_pending"] = True
                    break
        result = {"hours_advanced": actual_advanced, "hours_elapsed": rest["hours_elapsed"],
                  "light_after_each_hour": light_ticks,
                  "encounter_checks": checks,
                  "encounter_pending": rest["encounter_pending"]}
        return {"result": result, **self._commit("rest_advanced", result)}

    def complete_penance(self, pc_id: str, spell_name: str) -> dict[str, Any]:
        # 01, p. 48: priest must complete deity-appropriate penance before rest restores spell.
        pc = self._pc(pc_id)
        required = pc["spells"].get("penance_required", [])
        if spell_name not in required:
            raise ValueError("No penance is recorded for that spell")
        completed = pc["spells"].setdefault("penance_completed", [])
        if spell_name not in completed:
            completed.append(spell_name)
        result = {"pc_id": pc_id, "spell": spell_name,
                  "penance_completed": True,
                  "instruction": "spell returns only after a successful rest"}
        return {"result": result, **self._commit("penance_completed", result)}

    def finish_rest(self) -> dict[str, Any]:
        # 01, pp. 47–48, 89: successful rest restores HP/stat damage and rest-refresh abilities.
        rest = self.state["campaign"]["rest"]
        if not rest.get("active") or rest["hours_elapsed"] < 8:
            raise ValueError("A rest requires eight hours")
        if rest.get("encounter_pending"):
            raise ValueError("Resolve the pending rest encounter before completing rest")
        restored = []
        for pc_id in rest["pc_ids"]:
            pc = self._pc(pc_id)
            if pc_id in rest["failed_pc_ids"]:
                restored.append({"pc_id": pc_id, "benefit": "none: failed interruption check"})
                continue
            before = pc["hp"]["current"]
            pc["hp"]["current"] = pc["hp"]["maximum"]
            pc["stat_damage"] = {k: 0 for k in STAT_NAMES}
            spells = pc["spells"]
            for spell in list(spells.get("unavailable_until_rest", [])):
                if spell not in spells.get("penance_required", []):
                    spells["available"].append(spell)
                    spells["unavailable_until_rest"].remove(spell)
            for spell in list(spells.get("penance_required", [])):
                if spell in spells.get("penance_completed", []):
                    spells["available"].append(spell)
                    spells["penance_required"].remove(spell)
                    spells["penance_completed"].remove(spell)
                    if spell in spells.get("unavailable_until_rest", []):
                        spells["unavailable_until_rest"].remove(spell)
            restored.append({"pc_id": pc_id, "hp_before": before,
                             "hp_after": pc["hp"]["current"], "benefit": "rested"})
        rest.update({"active": False, "completed": True})
        return {"result": {"restored": restored}, **self._commit("rest_completed", {"restored": restored})}

    def gear_slots(self, pc_id: str) -> dict[str, int]:
        # 01, pp. 38–39: base capacity is STR or 10, whichever is higher.
        pc = self._pc(pc_id)
        gear = pc["gear"]
        base = max(pc["stats"]["STR"], 10)
        bonus = gear.get("explicit_slot_bonus", 0)
        used = sum(item["quantity"] * item["slots_each"] for item in gear["items"])
        limit = base + bonus
        return {"limit": limit, "used": used, "available": limit - used}

    def add_item(self, pc_id: str, item: dict[str, Any]) -> dict[str, Any]:
        pc = self._pc(pc_id)
        gear = pc["gear"]
        proposed = deepcopy(item)
        gear["items"].append(proposed)
        slots = self.gear_slots(pc_id)
        if slots["used"] > slots["limit"]:
            gear["items"].pop()
            raise ValueError("Item exceeds gear-slot capacity")
        result = {"pc_id": pc_id, "added": proposed, "slots": self.gear_slots(pc_id)}
        return {"result": result, **self._commit("item_added", result)}

    def award_treasure_xp(self, treasure_id: str, quality: str,
                          secured: bool = True) -> dict[str, Any]:
        # 01, pp. 42, 120: quality XP; each PC gets full award; XP resets on level.
        if quality not in TREASURE_XP:
            raise ValueError("Unknown treasure quality")
        if not secured:
            raise ValueError("Treasure XP is awarded only when treasure/boon is gained and secured")
        amount = TREASURE_XP[quality]
        for pc in self.state["pcs"]:
            pc["xp"] += amount
            threshold = pc["level"] * 10
            if pc["xp"] >= threshold:
                pc["xp"] = 0
                pc["level"] += 1
                hp_gain = self.die(pc["hit_die"])
                pc["hp"]["maximum"] += hp_gain
                pc["level_up_pending"] = True
        treasure = {
            "id": treasure_id, "quality": quality,
            "xp_value": amount, "secured": secured,
            "awarded_to": [pc["id"] for pc in self.state["pcs"]]
        }
        self.state["campaign"]["treasure_log"].append(treasure)
        return {"result": treasure, **self._commit("treasure_xp_awarded", treasure)}

    def luck_reroll_allowed(self, pc_id: str, critical_failure: bool = False,
                            luck_generating_effect: bool = False) -> bool:
        # 01, p. 82; 03, p. 29: Hard Luck Mode restrictions.
        pc = self._pc(pc_id)
        if pc.get("luck_tokens", 0) < 1:
            return False
        if self.state["campaign"].get("hard_luck_mode") and (
            critical_failure or luck_generating_effect
        ):
            return False
        return True

    def reroll_with_luck(self, pc_id: str, sides: int, count: int = 1,
                         modifier: int = 0, advantage: bool = False,
                         disadvantage: bool = False, critical_failure: bool = False,
                         luck_generating_effect: bool = False) -> dict[str, Any]:
        # 01, p. 82; 03, p. 29: reroll just-made dice and use the new result.
        if not self.luck_reroll_allowed(pc_id, critical_failure, luck_generating_effect):
            raise ValueError("Luck token is absent or prohibited by Hard Luck Mode")
        pc = self._pc(pc_id)
        if sides < 2 or count < 1:
            raise ValueError("Invalid reroll dice expression")
        pc["luck_tokens"] -= 1
        if sides == 20 and count == 1:
            new_roll = self.d20(modifier, advantage, disadvantage)
            result = {"pc_id": pc_id, "rerolled": new_roll,
                      "modifier": modifier, "total": new_roll["total"],
                      "luck_tokens_remaining": pc["luck_tokens"],
                      "instruction": "use this new result"}
        else:
            # For non-d20 pools, advantage/disadvantage compare complete pools.
            pools = [[self.die(sides) for _ in range(count)]
                     for _ in range(2 if advantage or disadvantage else 1)]
            totals = [sum(pool) for pool in pools]
            kept_index = (max(range(len(totals)), key=totals.__getitem__) if advantage
                          else min(range(len(totals)), key=totals.__getitem__) if disadvantage
                          else 0)
            kept = pools[kept_index]
            result = {"pc_id": pc_id,
                      "rerolled": {"expression": f"{count}d{sides}",
                                   "pools": pools, "kept": kept,
                                   "total": sum(kept)},
                      "modifier": modifier, "total": sum(kept) + modifier,
                      "luck_tokens_remaining": pc["luck_tokens"],
                      "instruction": "use this new result"}
        return {"result": result, **self._commit("luck_reroll", result)}

    def give_luck_token(self, from_pc_id: str, to_pc_id: str) -> dict[str, Any]:
        # 01, p. 82: a token may be given to a companion; each PC holds at most one.
        giver, recipient = self._pc(from_pc_id), self._pc(to_pc_id)
        if giver.get("luck_tokens", 0) < 1:
            raise ValueError("Giver has no luck token")
        if recipient.get("luck_tokens", 0) >= 1:
            raise ValueError("Recipient already holds the maximum one token")
        giver["luck_tokens"] -= 1
        recipient["luck_tokens"] += 1
        result = {"from": from_pc_id, "to": to_pc_id,
                  "giver_tokens": giver["luck_tokens"],
                  "recipient_tokens": recipient["luck_tokens"]}
        return {"result": result, **self._commit("luck_gifted", result)}

    def spend_luck_token(self, pc_id: str, sides: int, count: int = 1,
                         modifier: int = 0, advantage: bool = False,
                         disadvantage: bool = False,
                         critical_failure: bool = False,
                         luck_generating_effect: bool = False) -> dict[str, Any]:
        # Compatibility alias. Spending and rerolling are one atomic operation.
        return self.reroll_with_luck(
            pc_id, sides, count, modifier, advantage, disadvantage,
            critical_failure, luck_generating_effect
        )

    def reaches_weather(self) -> dict[str, Any]:
        # 02, p. 225: daily d6 weather; 6 gives advantage on next weather roll.
        travel = self.state["campaign"]["travel"]
        adv = travel.get("weather_advantage_next_roll", False)
        faces = [self.die(6), self.die(6)] if adv else [self.die(6)]
        kept = max(faces) if adv else faces[0]
        weather = "stormy" if kept == 1 else "excellent" if kept == 6 else "normal"
        travel["weather_advantage_next_roll"] = kept == 6
        result = {"dice": faces, "kept": kept, "weather": weather,
                  "advantage_used": adv}
        return {"result": result, **self._commit("reaches_weather", result)}

    def reaches_encounters(self, pushing: bool = False) -> dict[str, Any]:
        # 02, p. 225: 2 day + 2 overnight checks at 1:6; pushing adds one.
        slots = ["day-1", "day-2", "overnight-1", "overnight-2"]
        if pushing:
            slots.append("push-extra")
        checks = []
        for slot in slots:
            die = self.die(6)
            when = self.die(12) if die == 1 else None
            checks.append({"slot": slot, "d6": die,
                           "encounter": die == 1, "d12_time": when})
        result = {"checks": checks}
        return {"result": result, **self._commit("reaches_encounters", result)}

    def reaches_daily_rations(self, pc_ids: list[str], mount_ids: list[str] | None = None,
                              harsh_climate: bool = False) -> dict[str, Any]:
        # 02, pp. 225, 227: one ration per day; double in harsh climate or count as unfed.
        travel = self.state["campaign"]["travel"]
        day = self.state["campaign"]["clock"]["game_day"]
        if travel.get("last_daily_rations_day") == day:
            raise ValueError("Daily Reaches rations have already been resolved for this day")
        needed = 2 if harsh_climate else 1
        records = []
        for pc_id in pc_ids:
            pc = self._pc(pc_id)
            fed = self._consume_pc_rations(pc, needed)
            record = {"actor_id": pc_id, "rations_required": needed,
                      "rations_consumed": needed if fed else 0, "fed": fed}
            if not fed:
                pc["stat_damage"]["CON"] = pc.get("stat_damage", {}).get("CON", 0) + 1
                current_con = pc["stats"]["CON"] - pc["stat_damage"]["CON"]
                if current_con <= 0:
                    pc["hp"]["dead"] = True
                    pc["hp"]["dying"] = False
                record.update({"CON_damage": 1, "CON_remaining": current_con,
                               "dead": pc["hp"].get("dead", False)})
            records.append(record)
        for mount_id in mount_ids or []:
            mount = self._mount(mount_id)
            fed = mount.get("rations_count", 0) >= needed
            if fed:
                mount["rations_count"] -= needed
            else:
                mount["CON_damage"] = mount.get("CON_damage", 0) + 1
                current_con = mount["CON"] - mount["CON_damage"]
                if current_con <= 0:
                    mount["dead"] = True
            records.append({"actor_id": mount_id, "rations_required": needed,
                            "rations_consumed": needed if fed else 0, "fed": fed,
                            "CON_damage": 0 if fed else 1,
                            "CON_remaining": mount.get("CON", 0) - mount.get("CON_damage", 0),
                            "dead": mount.get("dead", False)})
        travel["last_daily_rations_day"] = day
        result = {"day": day, "harsh_climate": harsh_climate, "actors": records}
        return {"result": result, **self._commit("reaches_daily_rations", result)}

    def reaches_forage(self, pc_id: str, dc: int = 12,
                       harsh_climate: bool = False, stormy: bool = False,
                       pushing: bool = False) -> dict[str, Any]:
        # 01, p. 93; 02, pp. 225, 227: one ration/day; harsh-climate forage DC 18,
        # impossible in stormy weather; no foraging on a pushed day.
        if pushing:
            raise ValueError("Foraging is not allowed on a day the party pushed")
        if harsh_climate and stormy:
            result = {"pc_id": pc_id, "success": False,
                      "outcome": "foraging impossible in stormy harsh climate"}
            return {"result": result, **self._commit("reaches_forage", result)}
        target_dc = 18 if harsh_climate else dc
        result = self._check(pc_id, "INT", target_dc,
                             dc_source="02, p. 227 harsh climate forage" if harsh_climate else None)
        if result["success"]:
            pc = self._pc(pc_id)
            ration_item = next((x for x in pc["gear"]["items"]
                                if x.get("name", "").lower() == "ration"), None)
            if ration_item is None:
                ration_item = {"id": f"foraged-ration-{self.state['state_version'] + 1}",
                               "name": "ration", "quantity": 1, "slots_each": 1}
                pc["gear"]["items"].append(ration_item)
            else:
                ration_item["quantity"] += 1
            pc["gear"]["rations_count"] += 1
        result.update({"pc_id": pc_id, "target": f"DC {target_dc}",
                       "ration_gained": 1 if result["success"] else 0})
        return {"result": result, **self._commit("reaches_forage", result)}

    def reaches_daily_budget(self, method: str, pushing: bool = False) -> float:
        # 02, p. 225: 4 walking / 6 mounted / 8 sailing hexes per day.
        base = {"walking": 4, "mounted": 6, "sailing": 8}.get(method)
        if base is None:
            raise ValueError("Travel method must be walking, mounted, or sailing")
        return base * (1.5 if pushing else 1.0)

    def reaches_hex_cost(self, terrain: str) -> int | None:
        # 02, pp. 225–226: normal 1, difficult 2, impassable cannot enter.
        costs = {"normal": 1, "difficult": 2, "impassable": None}
        if terrain not in costs:
            raise ValueError(f"Unknown terrain: {terrain}")
        return costs[terrain]

    def advance_turn_order(self) -> dict[str, Any]:
        # Engine policy: ordered participants cycle; round increments after final turn.
        order = self.state["campaign"]["turn_order"].get("order", [])
        if not order:
            raise ValueError("Initiative/order has not been established")
        turn = self.state["campaign"]["turn_order"]
        turn["turn_index"] = turn.get("turn_index", 0) + 1
        if turn["turn_index"] >= len(order):
            turn["turn_index"] = 0
            turn["round"] = turn.get("round", 1) + 1
        turn["active_actor_id"] = order[turn["turn_index"]]
        result = {"round": turn.get("round", 1),
                  "turn_index": turn["turn_index"],
                  "active_actor_id": turn["active_actor_id"]}
        return {"result": result, **self._commit("turn_order_advanced", result)}

    def visible_state(self) -> dict[str, Any]:
        # Every public response should include this immutable snapshot.
        return deepcopy(self.state)
```

**Implementation notes / boundaries**

1. The reference class intentionally exposes every roll and state snapshot. It is suitable as a single-process prototype; a production host should persist the state JSON after every `_commit`, use request IDs for idempotency, and reject stale `state_version` values.
2. `advance_rest()` stops at the first encounter. Resolve that encounter and its interruption checks before advancing the remaining rest hours.
3. The LLM must retrieve the exact wizard mishap row and apply its specific consequence. The Python layer rolls the table die and records the pending result; the LLM is not allowed to invent a mishap.
4. Campaign-specific class features, creature abilities, magic items, and Reaches hex tables are retrieved as needed. They are not duplicated as new generic rules here.
5. If an operation is not present in the reference class, it is still an explicit engine command in the protocol, not an invitation for the LLM to mutate state. Add a deterministic function before using it in live play.

## 7. Anti-drift guardrails

### Forbidden

| Forbidden import or behavior | Why it is rejected |
|---|---|
| Bonus actions, permanent free extra actions, legendary actions, or D&D-style combat reactions | Breaks the one-action PC budget (01, pp. 86, 91; 02 adaptation framework, §2) |
| Concentration checks or concentration-breaking rules | Focus spells use their own spellcasting check at the start of the caster's turn (01, p. 53) |
| Spell slots, foreign spell levels, or short-rest spell recovery | Shadowdark uses known spells, tiers, spellcasting checks, and rest lockout (01, pp. 47–53) |
| Proficiency bonus or expertise arithmetic | Convert training to automatic success, relevant stat modifier, talent bonus, or advantage (02 adaptation framework, §2) |
| Challenge Rating (CR) as a Shadowdark difficulty or XP unit | Convert creatures to the Shadowdark level/role chassis; no universal CR conversion exists (02 adaptation framework, §§2, 4) |
| Encounter-day pacing or guaranteed daily recovery | Light, crawling rounds, random encounters, rations, and eight-hour rest create the pressure (01, pp. 85–89, 115) |
| Monster-kill XP as the default | Default XP is treasure/boon quality; Hunter Mode is a separate option (01, pp. 114, 120; 02 adaptation framework, §1) |
| Feet, squares, or tactical grids as the primary movement system | Use close/near/far (01, p. 88) |
| Invented DCs, hidden modifiers, fudged rolls, silent HP/XP/inventory/light edits | Breaks source resolution and the deterministic protocol |

### Required

1. **One PC action plus near movement.** If the PC declines an action, they may move near again. Only source-listed small multitasks remain incidental.
2. **Close/near/far.** Track relative position, not feet.
3. **DC ladder.** Use 9/12/15/18 for ordinary stat checks. Apply a different number only when an explicit source rule provides it, such as `10 + spell tier`, DC 12 rest interruption/camping defaults, DC 15 morale/first aid, or DC 18 harsh-climate foraging.
4. **Routine trained success.** No roll for a task that the character is trained to do when the correct area is searched and there is enough time.
5. **Visible dice.** Show every die, kept die, modifier, total, DC/AC, damage die, and outcome. No fudging.
6. **Real-time light.** Most sources run for about one real hour. Track actual elapsed time; at expiry, enforce darkness outside any remaining light.
7. **Encounter cadence.** Apply the exact priority in §5.12: darkness check every crawling round only when at least one active PC is not dark-adapted; rest uses 3/2/1 hours by danger; Reaches travel uses the four 1:6 checks (plus one if pushing); all other checks require an explicit GM trigger.
8. **Gear slots.** Enforce `max(STR, 10)` plus only printed bonuses.
9. **Rest.** Consume a ration and complete eight hours. Each stressful interruption calls for DC 12 CON by each affected PC. In a dangerous environment check encounters every 3/2/1 hours by danger level.
10. **Spell lockout.** Failed spells are unavailable until rest. Natural-1 wizard casting triggers mishap; priest casting requires penance and successful rest.
11. **Focus.** Check at the start of the caster's turn and immediately after damage/distraction.
12. **Dying.** Use `1d4 + CON modifier`, minimum one round. A natural 20 on a subsequent d20 returns the PC to 1 HP. DC 15 INT first aid at close range stabilizes, leaving the PC unconscious.
13. **Morale.** At half numbers or solo half HP, DC 15 WIS; failure means flee.
14. **Surprise.** Undetected creatures get their surprise turn before initiative.
15. **Luck.** One token maximum; reroll-and-take or gift to a companion. Apply Hard Luck Mode where active.
16. **XP.** Treasure quality and boons, not monster kills, drive default advancement.
17. **Travel precedence.** Reaches uses 02 travel/climate/camping/fast travel selected by 03; outside it, use 01 baseline.
18. **No unlogged state change.** If the number or status changes, the engine returns it and the DM displays it.

### Conversion gate for any imported content

Before adding an imported monster, item, spell, hazard, or NPC option, answer:

- What decision does it create for the player?
- What is its single action or source-defined turn behavior?
- Which Shadowdark stat, AC, HP, tier, range, and duration does it use?
- What is its trigger, consequence, resource cost, and recovery?
- Does it bypass light, gear slots, rations, rest, morale, or treasure XP?
- Is every new number supported by a source page? If not, label the number **adaptation proposal**.

No 5e field survives merely because it is present in the imported stat block. (02 adaptation framework, §§2–5)

## 8. Starter scenario — The Bell Under Sablewood

**Mode:** Western Reaches, using the 02 travel procedure to reach the site; core dungeon rules once inside.

### Hook

A bell has sounded beneath an abandoned stone waystation in the Sablewood. It rings once each night, though the bell tower above ground has collapsed. A local charcoal-burner offers a map to the sealed stair in exchange for the safe return of a bronze reliquary.

The waystation lies in a previously explored Sablewood hex. ### Four-room key

**Room 1 — The Flood Gate**

A stone hatch blocks the stairs. A rusted winch is jammed under a fallen beam. A character can inspect it and find the safest leverage point automatically if they take the time to examine it. Forcing the beam quickly is uncertain: use STR, normally DC 12. A failure costs time and makes noise; a loud disturbance can trigger an additional encounter check. The DC is a standard Normal check, not a custom value. (01, pp. 83–85, 115)

**Room 2 — The Bell Keeper**

One goblin stands near a cracked bronze bell, listening for footsteps. Use the printed goblin stat block, not a converted 5e goblin:

**Room 3 — The Silt Passage**

A shallow flooded passage divides the stair from the reliquary chamber. The stone lip is slick; a rusted tripwire is visible if a PC studies the doorway. Searching the correct area reveals the trap automatically. A trained thief with time and a reasonable method can disable it without a check. If a PC rushes across while the water is moving, call for a DEX check at a standard DC selected from 9/12/15/18 based on the actual danger. Failure causes the PC to lose their footing and makes noise; do not invent damage unless the keyed hazard supplies it. (01, pp. 84, 88, 117)

**Room 4 — The Reliquary Niche**

A bronze reliquary rests on a stone plinth behind a fallen screen. It contains a unique seal and the name of the waystation's last keeper. Recovering it is the adventure's reward. Treat the seal as **Fabulous treasure (3 XP per PC)** for this scenario. The quality classification is a GM reward decision; the source's XP category and award are not invented. Award XP only when the treasure is secured. (01, p. 120)

A narrow side alcove can be barricaded. It lowers the scene's danger to Unsafe for the purpose of this starter rest, an **adaptation proposal** about the fiction, not a new rest rule. If the party rests here, still check encounters every three hours. (01, p. 89)
